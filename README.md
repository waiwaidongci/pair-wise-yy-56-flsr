源提示词编号：13。覆盖构件与图纸焊缝台账、二维定位、焊工资质和检测比例预警、批量检测计划、缺陷记录、返修/复检状态、Apollo GraphQL 数据层、版本快照、签字锁定和完整追溯。

## 换版批次（图纸版本 → 焊缝 → 检测计划 → 签字锁定）

以"换版批次 RevisionBatch"把图纸版本、构件焊缝、检测计划和签字锁定串成一条链：

- **发版固定**：每个批次冻结图纸号（升版不改图号）、节点命名表和允许施工区，现场台账与检测计划都挂在批次下。
- **立即重算**：图纸版本一变（B 版确认生效），所有"待执行/执行中"检测计划按新节点命名和施工区状态立即重算；已完工计划不重算。
- **待映射不丢失**：B 版没有对应节点的旧焊缝（如 J-A5/W-109）暂挂旧节点号、回填"待映射"标记并生成阻断原因，必须补录映射，系统不静默删除。
- **并发裁决（先到先得）**：两名深化员各自保存 B 版确认草稿；先提交者换版生效，后提交者的改动原样保留在草稿中并看到冲突说明，可据此发起下一版。
- **写入失败恢复**：检测计划写入失败时标记失败，从"已确认条目"基线恢复，恢复明细标记"已恢复"待复核。
- **锁定快照**：阻断清零后方可签字锁定，锁定批次永远按原快照只读查看；四个页面（台账总览/构件定位/检测返修/审核锁定）共用同批修订与阻断原因视图。

演示路径：顶部"陈锋 · B 版确认"先提交 → "赵岚 · B 版确认"后提交触发冲突 → 检测页模拟写入失败并恢复 → 批次横幅逐条处理阻断（Z-3 放行 / W-109 补录映射）→ 审核页签字锁定 → 切换 A/B 批次标签对比快照。
